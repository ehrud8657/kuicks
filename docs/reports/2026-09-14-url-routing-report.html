1. 무엇이 바뀌었나

  • 브라우저 뒤로가기가 사이트 밖으로 나가지 않습니다. 앱 안의 이전 화면으로 돌아가고, 앞으로가기도 됩니다.
  • 새로고침하거나 주소를 공유해도 같은 화면이 열립니다. 스터디 관리 탭, 게시판 분류, 학기 선택까지 주소에 남습니다.
  • 주소로 상세 화면에 바로 들어와도 ← 버튼이 부모 화면으로 갑니다. 예: 출석 체크 → 출석 탭 → 스터디 관리 목록.
  • 저장하지 않은 출석이 있으면 나가기 전에 확인 창이 뜹니다. 앱의 ←, 브라우저 뒤로가기, 상단 메뉴 이동 모두 해당합니다. 이전에는 브라우저 뒤로가기로 나가면 확인 없이 사라졌습니다.
  • 권한에 따라 안내 화면이 나옵니다.
    • 로그인하지 않고 /me로 들어오면 “로그인이 필요합니다”
    • 정회원이 /manage로 들어오면 “볼 수 없는 페이지입니다”
    • 없는 주소는 “페이지를 찾을 수 없습니다”
    실제 권한 검사는 여전히 서버가 합니다.
  • 한글이 잠깐 ☒로 보이던 현상이 없어졌습니다. Pretendard 글꼴(SIL OFL)을 앱에 넣었고, 한글 글꼴을 외부에서 받아오는 요청이 0건입니다.
    • 대신 첫 로딩이 약 4.7MB 늘어납니다.
    • 엔진 파일(canvaskit)과 기본 Roboto는 원래대로 받습니다.

4. 검증

  • Flutter 위젯 테스트: test/router_test.dart 8개를 추가해 45개 모두 통과했습니다. 다룬 내용:
    • 주소로 바로 들어오기와 ← 두 번
    • 탭 주소 전환과 화면 재사용
    • 나가기 확인 (취소 / 나가기)
    • 로그인 안내, 권한 안내, 404
    • 끝 슬래시 정리와 게시판 분류
    • Q-04
  • Django: 로그인하지 않은 요청의 문구를 검사하도록 테스트를 고쳐 80개 모두 통과했습니다.
  • 실제 브라우저: 로컬 빌드 + 크롬(Playwright)에서 24개를 점검했습니다.
    • 경로 11개 새로고침
    • 앱 안 이동 후 브라우저 뒤로 3번·앞으로 1번
    • 저장 안 한 출석에서 브라우저 뒤로가기
    • Q-01·02·04
    • 콘솔 오류 0건, 한글 글꼴 외부 요청 0건
  • flutter analyze 문제 0건, flutter build web 성공.

점검 중 찾아 고친 것

  • 탭을 바꾸면 브라우저 방문 기록이 하나씩 쌓였습니다 (위젯 테스트로는 보이지 않고 실제 브라우저에서만 드러남). go_router의 replace만으로는 기록이 늘어나서, Router.neglect로 감쌌습니다. 학기 선택과 게시판 분류도 같습니다.
  • 상세 화면에서 돌아와도 마이페이지·관리 목록 수치가 갱신되지 않았습니다. push로 연 화면은 currentConfiguration.uri에 반영되지 않기 때문입니다. 맨 위 화면 기준인 router.state로 판단하도록 바꿨습니다.
  • Q-04 문구가 로그인 창에 가려 보이지 않았습니다. 그래서 로그인 창 안에 문구를 넣었습니다.

  • 직접 확인: 수동 체크리스트 M-05(실제 쓰는 브라우저에서 뒤로/앞으로·새로고침)와 Q-01~04를 한 번씩 봐주세요.

  • 로그인 창에서 취소: 로그인이 풀린 뒤 로그인 창을 취소하면, 보던 화면이 “로그인이 필요합니다” 안내로 바뀝니다. 작성 중이던 출석 변경은 저장되지 않습니다. 서버가 이미 막은 상태라 저장할 방법이 없습니다.
  • 아직 없는 주소: 게시글과 스터디 하나하나의 주소는 없습니다(/board/12 등). 지금 화면이 목록·펼치기 방식이라 필요해질 때 추가하면 됩니다.
  • 한글 줄바꿈: 긴 문장이 단어 중간에서 줄이 바뀌는 것은 Flutter의 한계로, 이번 글꼴 변경과 관계없습니다.
