# 눌리는 영역이 카드보다 좁은 문제 수정 계획

작성일: 2026-09-15 / 브랜치: `dev_tweho`

## 증상 (제보)

스터디 관리 목록에서 스터디 카드 오른쪽 부분은 마우스를 올려도 반응하지 않는다(커서가 손가락으로 바뀌지 않고, 눌러도 열리지 않음).

## 원인

- 구분 막대가 있는 카드(`SoftCard(accent: true)`)는 막대를 겹치기 위해 `Stack`을 쓴다.
- `Stack`의 기본 `fit: loose`는 안쪽 위젯에 폭 제한을 느슨하게 넘긴다.
- 그래서 카드 안 `InkWell → Column(start)`이 글자 폭만큼만 줄어든다.
- 결과적으로 카드의 오른쪽 빈 곳에는 눌리는 영역이 없었다.

## 재현 (수정 전, 실제 브라우저)

- 마우스를 카드 제목 높이에서 가로로 훑으며 커서 모양을 기록했다(`hover_audit.js`).
- 스터디 관리 카드(PC 1280)
  - 카드 폭: x 74~440
  - 손가락 커서가 나오는 구간: x 80~320
  - 오른쪽 약 120px가 반응하지 않았다.
- 같은 구조를 쓰는 Study·Board 카드는 펼침 제목(`ListTile`)이 원래 가로를 꽉 채워서 증상이 없었다.

## 수정

- `SoftCard`의 `Stack`에 `fit: StackFit.passthrough`를 줘서 카드 폭을 안쪽에 그대로 넘긴다.
- 사이트 전반에서 눌리는 곳(`InkWell`·`onTap`)을 전수 점검한다. 대상:
  - 상단 로고
  - 서랍 메뉴
  - Home·Contact·스터디 관리 카드
  - 출석 회차 줄, 과제 줄, 제출 파일 받기
  - 마이페이지 스터디 줄
  - 날짜·시각 선택 칸

## 확인

- **위젯 테스트 `test/tap_area_test.dart`**
  - `SoftCard`(막대 있음/없음) 안 `InkWell`의 폭이 카드 폭과 같고, 오른쪽 끝을 누르면 반응한다.
  - 스터디 관리 목록 카드의 오른쪽 끝을 누르면 스터디 관리 화면이 열린다.
- **실제 브라우저(PC 1280, 휴대폰 390)**: 카드 가로 전체에서 손가락 커서가 나오는지 다시 훑는다.

## 결과 (2026-09-15)

- **위젯 테스트**: `test/tap_area_test.dart` 3개를 추가해 전체 62개가 통과했다. `flutter analyze` 문제 0건.
- **실제 브라우저**
